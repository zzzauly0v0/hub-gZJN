# Qwen3.6 与 Qwen3.8 模型结构特点与改进对比

## 一、资料来源说明

| 文件 | 对应内容 |
| --- | --- |
| `qwen36_readme.md` | Qwen3.6-35B-A3B（MoE，35B 总参数 / 3B 激活） |
| `Qwen_38-README.md` | Qwen3.8-27B（27B Dense） |
| `Qwen_Qwen3.6-27B_config.json` | Qwen3.6-27B 的 Dense 配置 |
| `Qwen_Qwen3.8-config.json` | Qwen3.8-27B 的 Dense 配置 |

> 说明：`qwen36_readme.md` 描述的是 35B-A3B（MoE）版本，而两份 `config.json` 对应的是 27B Dense 版本，来源并不完全一一对应。因此下文分别从“README 结构规格”和“27B Dense 配置”两个层面对比，避免混淆。

## 二、结论速览

- 从 27B Dense 配置看，Qwen3.8-27B 与 Qwen3.6-27B 的 `text_config` 几乎完全一致，仅 `transformers_version` 不同；说明 Qwen3.8-27B 延续了 Qwen3.5/3.6 的 Dense 架构基础，改进主要来自训练与能力层面，而非底层结构重构。
- 若对比 README 中提供的 Qwen3.6-35B-A3B 与 Qwen3.8-27B，则两者是不同规模、不同结构的两条产品线：前者为 MoE，后者为 Dense。
- Qwen3.8 的核心提升集中在智能体执行、代码、专业工作、研究、长程任务、思维控制以及视觉理解，多个基准相比 Qwen3.6-27B 有明显提升。

## 三、结构特点对比

### 1. README 结构规格（Qwen3.6-35B-A3B vs Qwen3.8-27B）

| 维度 | Qwen3.6-35B-A3B | Qwen3.8-27B |
| --- | --- | --- |
| 模型类型 | Causal LM + Vision Encoder | Causal LM + Vision Encoder |
| 总参数 / 激活参数 | 35B / 3B（MoE） | 27B（Dense） |
| 隐藏维度 | 2048 | 5120 |
| 词表大小 | 248320（Padded） | 248320（Padded） |
| 层数 | 40 | 64 |
| 层布局 | 10 × (3 × (Gated DeltaNet → MoE) → 1 × (Gated Attention → MoE)) | 16 × (3 × (Gated DeltaNet → FFN) → 1 × (Gated Attention → FFN)) |
| Gated DeltaNet 头数 | 32（V）/ 16（QK） | 48（V）/ 16（QK） |
| Gated DeltaNet 头维度 | 128 | 128 |
| Gated Attention 头数 | 16（Q）/ 2（KV） | 24（Q）/ 4（KV） |
| Gated Attention 头维度 | 256 | 256 |
| RoPE 维度 | 64 | 64 |
| FFN 中间维度 | — | 17408 |
| MoE | 256 个专家，激活 8 路由 + 1 共享，专家中间维度 512 | 无（Dense FFN） |
| MTP | 多步训练 | 多步训练 |
| 原生上下文长度 | 262144，可扩展至 1010000 | 262144，可扩展至 1000000 |

### 2. 27B Dense 配置对比（两份 config.json）

两份 27B Dense 配置在以下关键结构参数上完全一致：

- 架构：`Qwen3_5ForConditionalGeneration`，`model_type: qwen3_5`
- 隐藏维度：5120；层数：64；FFN 中间维度：17408
- 注意力：24 个 Q 头、4 个 KV 头，`head_dim: 256`
- 线性注意力：16 个 QK 头、48 个 V 头，`linear_key/value_head_dim: 128`，`linear_conv_kernel_dim: 4`
- 层类型：`full_attention_interval: 4`，即每 4 层中 3 层为 `linear_attention`、1 层为 `full_attention`
- RoPE：`rope_theta: 10000000`，`partial_rotary_factor: 0.25`，M-RoPE 分段 `[11, 11, 10]`
- 最大位置编码：262144；词表：248320
- MTP：`mtp_num_hidden_layers: 1`，`mtp_use_dedicated_embeddings: false`
- 视觉编码器：27 层，隐藏维度 1152，`patch_size: 16`，`out_hidden_size: 5120`

唯一明显差异：`Qwen_Qwen3.6-27B_config.json` 的 `transformers_version` 为 `4.57.1`，`Qwen_Qwen3.8-config.json` 为 `5.8.0.dev0`。

## 四、Qwen3.8 的改进点

### 1. 能力方向（来自 Qwen3.8 README）

- **核心能力**：在代码、专业工作、研究和长程智能体任务上全面提升。
- **智能体执行**：自主规划更强，对环境反馈的处理更好，端到端任务完成更可靠。
- **下游兼容性**：更广泛支持主流评测框架与开发工具，便于集成到现有工作流。
- **灵活思维控制**：默认开启思维模式，可单请求关闭；可用 `reasoning_effort` 调节推理深度；通过 `preserve_thinking` 保留历史推理上下文。
- **原生视觉语言理解**：原生支持图像与视频理解，覆盖 STEM 图表、文档以及小时级视频。

## 五、部署、思维控制与长文本变化

- **思维控制**：Qwen3.6 引入了“思考保留（Thinking Preservation）”；Qwen3.8 进一步将其系统化，默认保留全部历史推理块，并新增 `reasoning_effort` 调参与非思考模式开关。
- **推理框架**：Qwen3.6 README 列出 SGLang、vLLM、KTransformers、HF Transformers；Qwen3.8 列出 HF Transformers、vLLM、SGLang、TokenSpeed，并推荐优先使用 API。
- **托管服务**：Qwen3.8 提供 Qwen Cloud 托管版本，默认 1M 上下文并内置官方工具；Qwen3.6 README 未强调这一托管能力。
- **长文本**：两者原生均为 262144 token，均可通过 YaRN 扩展到约 100 万 token；Qwen3.8 的最佳实践中进一步细化了 1M 上下文内推理输出（262144）与最终回答输出（131072）的 token 分配建议。

## 六、总结

Qwen3.8-27B 在 27B Dense 架构上基本继承 Qwen3.6-27B 的结构（配置几乎相同），因此其升级主要体现为训练、后训练与产品能力层面的改进：
更强的代码与智能体执行、更完善的思维控制机制、更好的视觉语言理解，以及更广泛的生态兼容性。若与 README 中提供的 Qwen3.6-35B-A3B 相比，
则还体现出 MoE 与 Dense 两条产品线的定位差异：35B-A3B 以更少的激活参数换取规模，而 Qwen3.8-27B 以 Dense 结构换取部署友好性与稳定的单模型性能。
