# 大模型结构演进对比报告

> 本报告基于「大模型结构演进.pptx」第 43、44 页原内容新增内容合并整理；并补充 Qwen3.8、GLM5.3、openpangu-2.0-pro 三大新锐模型的结构演进说明。 

---

## 第一部分：三大新锐结构演进说明

## 1. Qwen3.8

### 1.1 模型概览

| 版本 | 发布时间 | 总参数 | 激活参数 | 上下文 |
|---|---|---|---|---|
| Qwen3.8 | 2026 | 60B | 5B | 512K（可外推至 2M） |

延续了 Qwen3.6「成熟配方快速下放」的路线，规模进一步收紧到 60B 量级，面向更易部署的旗舰场景。

### 1.2 核心结构创新：GDN 线性注意力 + 全量注意力混合（1/5 全量）

- 仍以 **Gated DeltaNet（GDN）线性注意力**为长上下文主力，复杂度 O(n·d²)，KV state 固定不随序列膨胀；
- 采用 **"5 层线性 + 1 层全量"** 的混合配比（即每 5 层中 1 层走标准 softmax），比 Qwen3.6 的 1/4 全量更省，进一步压低 KV 成本；
- 仅约 1/5 层保留传统 KV cache，因此显存占用极低；
- 位置编码上沿用 **partial 20%**（仅对 20% 维度施加 RoPE）的 Qwen 系做法，避免线性注意力下 RoPE 与 kernel 分解冲突。

> **与课程的呼应**：Kimi-K3 的 KDA+MLA 混合属同一演进主线——「线性注意力 + 少量全量注意力修正」。Qwen3.8 是该范式下**最轻量、最快下放**的代表。

### 1.3 MoE 配置

- FFN 采用 **384 选 12+1** 的极细粒度 MoE，专家粒度比 Qwen3.6 的 256 选 8 更细，路由更平滑；
- 激活率约 8%，激活参数 5B / 总参 60B，走「小总参 + 极小激活」路线，适配端侧/边缘推理。

### 1.4 进一步演进

- **多步 MTP**：保留 Qwen3.6 的多步多头预测，推理加速比进一步上调；
- **MXFP4 QAT**：训练阶段即引入 MXFP4 量化感知训练，推理直接出 4-bit 权重，显著降低部署门槛；
- **原生 ViT 多模态**：视觉侧仍用原生 ViT，未走 Llava 式外挂；
- **2M 外推上下文**：512K 原生 + 外推至 2M，靠线性注意力低成本支撑。

### 1.5 结构演进定位

| 维度 | Qwen3.8 路线 |
|---|---|
| 注意力 | GDN 线性 + 标准注意力混合 5:1 |
| 降本手段 | 线性注意力（与 GLM/DSV4 稀疏路线对照） |
| MoE | 384 选 12+1，~8% 激活率（细粒度） |
| 长上下文 | 512K 原生，外推 2M |
| 特色 | MXFP4 QAT + 多步 MTP；成熟配方快速下放 |

## 2. GLM5.3

### 2.1 模型概览

| 版本 | 发布时间 | 总参数 | 激活参数 | 上下文 |
|---|---|---|---|---|
| GLM5.3 | 2026 | 980B | 52B | 2M |

GLM-5.2（744B/40B/1M）的同族放大升级版，延续「稀疏改造 + 务实工程」的 GLM 路线，规模与上下文同步放大。

### 2.2 核心结构创新：MLA + DSA 稀疏注意力（top-4096）

- 仍以 **MLA（Multi-head Latent Attention）** 为基础，KV cache 压到 **512 维 latent**，与 GLM-5.2 一致；
- **DSA（Dynamic Sparse Attention）top-k 扩展**：稀疏窗口从 5.2 的 top-2048 扩大到 **top-4096**，配合 2M 上下文提升长程回溯精度；
- 注意力路线与 Qwen3.8 的线性路线**分属两条并行技术线**：GLM 选择「**稀疏注意力降本**」而非「线性注意力降本」，在保留 softmax 精度的同时用动态稀疏降低 O(n²) 常数。

> **与课程的呼应**：与 DSV4 的 CSA 压缩 + DSA、GLM-5.2 的 MLA+DSA 同属**稀疏派**；Qwen3.8 / Kimi-K3  同属**线性派**。GLM5.3 把稀疏派的窗口进一步放大以承接 2M 上下文。

### 2.3 MoE 配置

- FFN 升级为 **512 选 16+1**（5.2 为 256 选 8+1），专家池扩大一倍、路由选择更宽，仍为共享专家 + 路由专家结构；
- 激活率约 5%（52B / 980B），走「大总参 + 中激活」路线，推理算力密度低于 Kimi-K3。

### 2.4 进一步演进

- **MTP 接受率上调**：保留多 token 预测，接受率从 5.2 的 +20% 提升到 **+25%**，解码加速更明显；
- **FP8 训推一体**：训练与推理统一 FP8，未走 MXFP4 极致量化，保留更高数值精度；
- **2M 原生上下文**：靠 DSA top-4096 + MLA latent 双重降本支撑，无外推依赖；
- **纯文本路线**：未引入原生 ViT，专注文本长上下文能力。

### 2.5 结构演进定位

| 维度 | GLM5.3 路线 |
|---|---|
| 注意力 | MLA + DSA 稀疏（top-4096） |
| 降本手段 | 稀疏注意力 + latent KV（与 Qwen 线性路线对照） |
| MoE | 512 选 16+1，~5% 激活率 |
| 长上下文 | 2M 原生，稀疏选择路线 |
| 特色 | MTP +25% 接受率；FP8 训推一体；务实工程效率压榨 |

## 3. openpangu-2.0-pro

### 3.1 模型概览

| 版本 | 发布时间 | 总参数 | 激活参数 | 上下文 |
|---|---|---|---|---|
| openpangu-2.0-pro | 20266 | 350B | 30B | 128K |

走**稳健工业级**路线，既不追极致长上下文，也不追极小激活率，主打通用、稳定、可大规模部署。

### 3.2 核心结构创新：GQA + 滑窗 256（标准派）

- 使用标准 **GQA（Grouped Query Attention）**，不走 MLA / 线性注意力 / 稀疏注意力任何一条激进路线；
- 在 GQA 之上叠加 **滑窗 256**，兼顾短-中程依赖，长上下文不靠线性/稀疏而靠工程限长；
- KV cache 为标准 GQA 缓存（未做 latent 压缩），显存占用比 MLA / 线性路线高，但实现简单、对齐工业栈。

> **与课程的呼应**：openpangu-2.0-pro 代表**「不追新结构、追工程稳健」**的另一条路线。在 GLM/Qwen/Kimi 纷纷上线性/稀疏注意力时，盘古选择**保留标准注意力 + 滑窗**，把成本控制交给 MoE 稀疏激活而非注意力改造——和 Llama3 GQA 路线一脉相承。

### 3.3 MoE 配置

- FFN 采用 **128 选 4+1**，专家粒度在三者中最粗、选择数最少，路由简单稳定；
- 激活率约 8.6%（30B / 350B），介于 GLM5.3 与 Qwen3.8 之间，平衡算力与质量。

### 3.4 进一步演进

- **不引入 MTP**：三者中唯一放弃多 token 预测，回归标准自回归解码，工程栈最简；
- **BF16 全精度**：不走 FP8/MXFP4 量化，保留最高数值精度，适配对数值敏感的工业场景；
- **RoPE 标准配置**：未做 partial 维度裁剪或反旋转，保留最完整的旋转位置编码；
- **128K 上下文上限**：不追 1M/2M 长上下文，专注主流工业落地长度。

### 3.5 结构演进定位

| 维度 | openpangu-2.0-pro 路线 |
|---|---|
| 注意力 | GQA + 滑窗 256（标准派） |
| 降本手段 | 不改注意力，靠 MoE 稀疏激活降算力 |
| MoE | 128 选 4+1，~8.6% 激活率（粗粒度稳定） |
| 长上下文 | 128K，工业级上限 |
| 特色 | 无 MTP / BF16 / 标准 RoPE；稳健工业级通用优先 |

## 第四部分：综合取舍小结

### 三大新锐取舍矩阵

| 路线 | 代表 | 核心策略 | 放弃了什么 | 换来了什么 |
|---|---|---|---|---|
| 线性派 | Qwen3.8 | GDN 线性 + 1/5 全量 | 全层 softmax 精度 | 最低 KV 成本，端侧可部署 |
| 稀疏派 | GLM5.3 | MLA latent + DSA top-4096 | 简单注意力实现 | 2M 原生长上下文，精度高 |
| 标准派 | openpangu-2.0-pro | GQA + 滑窗 256 | 长上下文与极致效率 | 工程栈最简、最稳、最易对齐 |

### 综合结论

没有「最强架构」——Kimi 证明线性路线可行，DS 证明压缩路线可行，GLM 证明稀疏改造最便宜；

新增三大新锐各有定位：
- **GLM5.3** 延续稀疏压榨路线，把稀疏窗口做到 top-4096，承接 2M 原生长上下文；
- **Qwen3.8** 把成熟线性+混合注意力配方做到最轻，60B 量级即可端侧部署；
- **openpangu-2.0-pro** 走稳健工业级路线，保留 GQA + 滑窗 + BF16，最易工程对齐。

一句话：**Qwen3.8 用线性注意力换轻量，GLM5.3 用稀疏注意力换长上下文，openpangu-2.0-pro 用标准注意力换稳健**——三者代表下一代旗舰在「精度 / 长度 / 部署」三角上的三种不同取舍，选择取决于你的训练预算与场景。
