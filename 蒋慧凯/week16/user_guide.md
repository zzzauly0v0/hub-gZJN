# Week 16 作业使用说明

## 项目简介

Week 16 课程主题是「大模型结构演进」，课堂重点讲解了 DeepSeek-V3 / V4、GLM-5.2、Kimi-K3、Qwen3.6 四大旗舰的结构变化。

本作业调研了课堂上未展开讲解的三个开源模型：

- Meta **Llama 4**
- Google **Gemma 3**
- Microsoft **Phi-4-mini / Phi-4-Multimodal**

从注意力机制、MoE 化、位置编码、多模态接入等角度总结它们的结构特点，并与课程内容做横向联系。

## 文件结构

```
homework/
├── README.md                     # 完整调研报告与学习笔记
└── user_guide.md                 # 本使用说明
```

## 环境要求

本作业为纯 Markdown 阅读型报告，无需运行代码。

- 阅读工具：任意 Markdown 编辑器或 VS Code
- 无需安装 Python 依赖

## 输入输出与运行方式

1. 打开 `README.md` 即可阅读完整调研报告。
2. 报告包含每个模型的结构特点、横向对比表、与课堂内容的联系、参考资料链接。
