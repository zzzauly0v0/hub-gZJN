# 作业：三种小型大语言模型的结构对比分析

## 一、作业目的

本次作业选择三个参数量不超过 6B、由知名公司发布的模型，通过阅读模型配置和源码，分析现代大语言模型在位置编码、归一化、注意力、FFN、残差连接和推理加速方面的结构设计。

选择的模型如下：

- 阿里通义千问：`Qwen/Qwen3.5-4B-Base`
- 微软：`microsoft/Phi-4-mini-flash-reasoning`
- Mistral AI：`mistralai/Ministral-3-3B-Base-2512`

Qwen3.5 和 Ministral 3 同时包含视觉编码器，但本次作业只分析与“Transformer 结构演进”课程相关的语言模型主干。

分析依据包括模型的 `config.json`、模型卡、模型源码和权重索引。本次作业主要关注模型结构，不下载真实权重，也不进行推理速度、显存占用和生成质量测试。

## 二、模型选择与分析思路

三个模型都使用 Dense SwiGLU FFN，没有使用 MoE，最主要的区别在于如何处理历史信息：

| 模型 | 整体路线 | 主要目的 |
|---|---|---|
| Qwen3.5-4B | 24 层 Gated DeltaNet + 8 层完整注意力 | 大部分层用固定记忆状态降低长文本成本，少量完整注意力负责精确检索 |
| Phi-4-mini-flash | Mamba/SSM + 滑动窗口注意力 + 共享全局 KV | 同时压缩计算量和 KV Cache，并让上半部分网络复用同一份全局记忆 |
| Ministral-3-3B | 26 层完整 GQA | 保留标准 Transformer 结构，主要通过 GQA 和 YaRN 支持高效长上下文 |

本次作业将三个模型分别作为三种结构路线的代表：

- Ministral：标准 Transformer 对照组。
- Qwen：线性注意力与完整注意力混合。
- Phi：状态空间模型、局部注意力和共享全局记忆混合。

## 三、Qwen3.5-4B-Base 结构分析

### 整体结构

- 隐藏维度：2560
- 层数：32
- FFN 中间维度：9216
- 层排列：重复 8 次“3 层 Gated DeltaNet + 1 层完整注意力”
- 配置上下文：262,144 token
- FFN：Dense SwiGLU，不是 MoE

### 位置编码：Partial RoPE

- 完整注意力层使用 RoPE。
- `head_dim=256`，`partial_rotary_factor=0.25`，即每个 Q、K 头只有 64 维使用 RoPE。
- 其余 192 维不旋转，可以更多地用于内容匹配。
- Gated DeltaNet 层本身不使用 RoPE，而是依靠递归记忆状态和短卷积表达顺序。

这正好对应笔记中的 Partial RoPE：位置匹配与内容匹配在不同维度上分工。

### 归一化

- 主干使用 Pre-RMSNorm：每个 Token Mixer 和 FFN 之前先做 RMSNorm。
- 完整注意力层另外对每个头的 Q、K 分别做 RMSNorm，即 QK-Norm。
- RMSNorm 内部先用 FP32 计算平方均值，再转回输入精度，有助于低精度下的数值稳定。

### 注意力与记忆

完整注意力层：

- 16 个 Q 头、4 个 KV 头，属于 GQA。
- 每 4 个 Q 头共享一组 K、V，减少完整注意力层的 KV Cache。
- Q 投影同时生成一个门值，注意力输出乘以 `Sigmoid(gate)` 后再经过输出投影，属于输出门控。

Gated DeltaNet 层：

- 共 24 层，是模型的主要 Token Mixer。
- 使用 16 个 Key 头和 32 个 Value 头，内部维护固定大小的递归记忆状态。
- 每个 token 对记忆执行衰减、更新和读取，不需要保存这一层的全部历史 K、V。
- 在进入递归记忆前还有长度为 4 的深度卷积，用于提取短距离顺序信息。

因此，Qwen3.5 不是“完全线性注意力模型”：24 层的状态更新接近线性成本，但仍保留 8 层完整注意力，后者仍有平方级 Prefill 计算和随长度增长的 KV Cache。

### FFN 与残差

- FFN 是标准 SwiGLU：`Down(SiLU(Gate(x)) × Up(x))`。
- 每层只有一个 Dense FFN，没有路由器和专家，因此没有 MoE。
- 使用普通单路残差连接，没有 mHC 或 AttnRes。

### MTP

- 配置中 `mtp_num_hidden_layers=1`，权重索引也确实包含一组 `mtp.*` 参数。
- 说明模型检查点带有一个轻量 MTP 预测层，可供支持它的推理框架进行投机解码。
- 当前通用 Transformers 主类会忽略 `mtp.*` 权重，因此“检查点包含 MTP”不等于普通 `generate()` 会自动启用投机解码。

### 对课程笔记的对应

`Partial RoPE + RMSNorm + QK-Norm + GQA + Gated DeltaNet + 输出门控 + SwiGLU + MTP`

## 四、Phi-4-mini-flash-reasoning 结构分析

### 整体结构

- 参数规模：约 3.8B
- 隐藏维度：2560
- 层数：32
- FFN 中间维度：10240
- 架构名称：SambaY
- 官方支持上下文：64K；配置中的 `max_position_embeddings` 为 262,144，不能直接视为已经验证的有效上下文长度

### 位置编码：NoPE

- 模型没有显式 RoPE 或绝对位置编码。
- 顺序信息主要来自因果 Mamba/SSM 状态、长度为 4 的因果卷积以及因果注意力掩码。
- 这对应笔记中的 NoPE：不是整个模型没有顺序信息，而是注意力层不再单独添加位置编码。

### SambaY：两阶段混合结构

32 层中，偶数层使用 Mamba/SSM，奇数层使用注意力，大致可以拆成两部分：

1. 下半部分 Self Decoder
   - Mamba 与窗口为 512 的局部注意力交替。
   - Mamba 将历史压缩到固定大小状态；局部注意力保留最近 token 的细节。

2. 上半部分 Cross Decoder
   - 中间位置构建一份全局 K、V 记忆。
   - 后续注意力层只产生 Q，并复用这份全局 K、V，不再每层保存独立 KV Cache。
   - 后续 Mamba 层也通过门控读取共享状态，这部分称为 Gated Memory Unit（GMU）。

它比普通 GQA 更进一步：GQA 是“同一层的多个 Q 头共享 K、V”，SambaY 还让“多个后续层共享同一份全局记忆”。

### 差分注意力

- 将 Q、K 分成两组，分别计算两个注意力结果。
- 最终输出形式近似为 `Attention1 - λ × Attention2`。
- 主要作用是利用相减抑制两组注意力共同包含的噪声，突出有区分度的信息。

### 归一化、FFN与残差

- 使用 Pre-RMSNorm。
- FFN 使用 Dense SwiGLU，没有 MoE。
- 采用普通单路残差连接，没有 mHC 或 AttnRes。
- 词嵌入和输出层共享权重，减少参数量。

### 对课程笔记的对应

`NoPE + RMSNorm + GQA + 滑动窗口 + 固定记忆状态 + 共享 KV Cache + SwiGLU`

差分注意力和跨层共享全局 KV 是这份课件笔记之外值得补充的两个点。

## 五、Ministral-3-3B-Base-2512 结构分析

### 整体结构

- 隐藏维度：3072
- 层数：26
- FFN 中间维度：9216
- 配置上下文：262,144 token
- 所有 26 层均为完整因果自注意力，没有线性注意力或 SSM

### 位置编码：RoPE + YaRN

- 所有注意力层使用 RoPE。
- 原始位置范围为 16,384，YaRN 外推倍率为 16，配置长度扩展到 262,144。
- 这直接对应笔记中的 YaRN：通过调整不同频率的旋转尺度扩展上下文长度。

需要注意：YaRN 扩展了可用位置范围，但并没有消除完整注意力的平方级计算量。

### 注意力

- 32 个 Q 头、8 个 KV 头，属于 GQA。
- 每 4 个 Q 头共享一组 K、V。
- 没有滑动窗口，所有 26 层都能查看完整历史。
- 没有 MLA、线性注意力、稀疏注意力和输出门控。

因此它的优点是结构简单、历史细节保留完整；代价是长文本 Prefill 计算和 KV Cache 仍然较大。

### 归一化、FFN与残差

- 使用 Pre-RMSNorm。
- FFN 使用 Dense SwiGLU，没有 MoE。
- 使用普通单路残差连接，没有 mHC 或 AttnRes。
- 输入词嵌入与输出层共享权重。

### 对课程笔记的对应

`RoPE + YaRN + RMSNorm + GQA + SwiGLU`

它最适合作为标准现代 Dense Transformer 的对照模型。

## 六、横向对比与总结

| 维度 | Qwen3.5-4B | Phi-4-mini-flash | Ministral-3-3B |
|---|---|---|---|
| 公司 | 阿里 | 微软 | Mistral AI |
| 语言层数 | 32 | 32 | 26 |
| 隐藏维度 | 2560 | 2560 | 3072 |
| Token Mixer | 24 Gated DeltaNet + 8 完整注意力 | 16 Mamba/SSM + 16 注意力 | 26 完整注意力 |
| 位置方案 | Partial RoPE，仅完整注意力层使用 | NoPE | RoPE + YaRN |
| KV 优化 | GQA；线性层使用固定状态 | GQA、窗口缓存、跨层共享全局 KV | GQA |
| QK-Norm | 有 | 未见独立 QK-Norm | 无 |
| 输出门控 | 有 | 无同类 Sigmoid 输出门 | 无 |
| FFN | Dense SwiGLU | Dense SwiGLU | Dense SwiGLU |
| MoE | 无 | 无 | 无 |
| 特殊推理结构 | 1 层 MTP | 共享记忆降低解码成本 | 无 |
| 残差结构 | 普通单路残差 | 普通单路残差 | 普通单路残差 |

通过对比可以看出，三个模型的 FFN 和残差结构差异不大，结构演进主要集中在注意力和长上下文处理上：

- Ministral 3 保留完整注意力，通过 GQA 减少 KV Cache，并使用 YaRN 扩展上下文长度。
- Qwen3.5 用 Gated DeltaNet 替代大部分完整注意力层，在降低长文本成本的同时保留少量完整注意力进行精确检索。
- Phi-4-mini-flash 进一步使用 Mamba、滑动窗口和跨层共享 KV，并通过 NoPE 避免显式位置编码。

因此，这三个模型分别体现了现代 Transformer 的三种演进思路：优化原有注意力、混合线性注意力，以及引入状态空间模型。
