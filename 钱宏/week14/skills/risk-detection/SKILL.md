# 多工单交叉作业风险检测 Skill

根据传入的作业工单信息（作业类型、区域、位置、时间窗口），与已有工单数据进行比对，检测同一时空范围内的冲突作业，返回风险信息字符串。

## 触发场景

当用户说出类似下面的话时触发本 skill：
- "检测化工一车间动火作业 2024-01-15 09:00~12:00 的风险"
- "动火作业 储罐区 2024-01-15 14:00~17:00 有没有冲突"
- "列出所有工单"
- "查看工单 WT-2024-001 的详情"

## 风险检测规则

1. **动火 + 装卸料**（同区域 + 时间重叠）→ 火灾爆炸风险（严重）
2. **动火 + 盲板抽堵**（同区域 + 时间重叠）→ 有毒气体泄漏风险（严重）
3. **3处以上交叉作业**（同区域 + 时间重叠）→ 人员伤害风险（中等）
4. **动火 + 检修（含易燃物料）**（同区域 + 时间重叠）→ 安全管控风险（中等）

## 输出格式

- 传入工单信息摘要
- 比对工单数量（同区域时间重叠）
- 冲突列表（含冲突工单编号、作业类型、位置、时间窗口）
- 风险描述（含风险等级、风险类型、建议措施）
- 直接返回 String，不生成 HTML
